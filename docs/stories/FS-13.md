## Story

As a Resolver, I want to see an "AI Root Cause Assistant" panel in the Investigation Workspace so that the feature surface is visible in the MVP and can be wired to a real AI model in a future sprint.

## Acceptance Criteria

1. The Investigation Workspace right column contains an "AI Root Cause Assistant" card below the checklist.
2. The card displays descriptive placeholder text explaining what the AI will do when enabled (e.g., "Analyse investigation notes and suggest likely root causes").
3. A "Generate Suggestions" button is visible but **disabled** (greyed out) in the MVP — it does not call any backend.
4. The card does not throw any runtime errors and renders without data dependencies.

## Dev Notes

**No backend work.** This story is frontend-only; the API endpoint and AI integration are deferred to a future Epic.

**Why a stub?** Figma shows the AI panel in the workspace layout. Implementing it as a disabled stub keeps the UI faithful to Figma and reserves the slot so future wiring does not require a layout change.

**Button disabled state:** `[disabled]="true"` with `opacity: 0.5; cursor: not-allowed` CSS. Add a tooltip or sub-label "Coming soon" to set expectations.
