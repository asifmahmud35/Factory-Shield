## Story

As a Resolver, I want to see a dashboard of incidents assigned to me so that I can prioritise and begin investigating them.

## Acceptance Criteria

1. Given I'm authenticated as Resolver, when I call `GET /api/v1/resolver/assigned`, then the API returns only incidents where `AssignedResolverId == me` and status is not Closed/Rejected, sorted by severity ascending (1=Critical first) then createdAt ascending.
2. Given I navigate to `/resolver/assigned` in the Angular app, then I see a table listing my assigned incidents with columns: Incident No, Category, Severity, Status, Created.
3. Given no incidents are assigned to me, then the table shows "No incidents currently assigned to you."
4. Given a Reporter or Approver tries to call `GET /api/v1/resolver/assigned`, then they receive HTTP 403 Forbidden.
5. Given a Resolver is not the same user as `AssignedResolverId`, then their incidents are not shown (each resolver sees only their own).

## Dev Notes

**Claim extraction:** JWT `sub` claim is mapped to `ClaimTypes.NameIdentifier` by ASP.NET Core JWT middleware. Controller reads it with `User.FindFirstValue(ClaimTypes.NameIdentifier)`.

**Display status:** Uses existing `DisplayStatusMapper.Map()` — assigned incidents in states ASSIGNED/IN_PROGRESS will both show "In Progress" to the Resolver.
