## Story

As a Resolver, I want to check off investigation checklist items as I complete them, so I can track which mandatory investigation steps have been performed.

## Acceptance Criteria

1. When I open the Investigation Workspace, the checklist shows all 8 seeded items in their correct order with a checkbox (or visual indicator) for each.
2. When I click a checklist item that is incomplete, the API marks it as complete (`IsCompleted=true`, `CompletedAt=UtcNow`) and returns the updated counts.
3. When I click a checklist item that is already complete, the API toggles it back to incomplete (`IsCompleted=false`, `CompletedAt=null`).
4. The response returns `{ isCompleted, completedCount, totalCount }` so the UI can update the progress summary without a full reload.
5. If the `itemId` does not belong to the given `incidentId`'s investigation, the API returns HTTP 404.

## Dev Notes

**Toggle logic:** Simple flip — if `IsCompleted` is `false`, set to `true` and `CompletedAt = UtcNow`; if `true`, set to `false` and `CompletedAt = null`.

**Count query:** After toggle, handler counts all checklist items for the investigation to return accurate `completedCount` and `totalCount` (avoids stale in-memory count).

**Security:** Verify the item belongs to the incident's investigation — return 404 if not, never 403, to avoid leaking existence.
